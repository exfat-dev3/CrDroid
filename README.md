# CzeDroid 🤖

## English

CzeDroid is an Android application for creating fake error dialogs inspired by Crazy Error.

### Features
- Create custom fake error dialogs
- Customize title, message, buttons, and icon
- Easy-to-use interface
- Export and share your creations
